1. On-Page SEO Critical
Dynamic <title> tag HTML
Each page must have a unique title. Format: Post Title | Site Name for posts, Site Name — Tagline for homepage. Keep under 60 characters.
<title>How to Deploy on Kubernetes | codecloudworld</title>
Meta description HTML
Unique 150-160 character description per page. This is what Google shows below your title in search results. Include target keywords naturally.
<meta name="description" content="Step-by-step guide to deploying apps on Kubernetes with Helm charts, rolling updates, and monitoring.">
Canonical URL HTML
Prevents duplicate content issues. Every page must have one. Points to the "official" version of the page.
<link rel="canonical" href="https://yourblog.com/2026/01/my-post.html">
lang attribute on <html> HTML
Tells Google the language of your content. Helps with international SEO and accessibility.
<html lang="en">
Proper heading hierarchy HTML
One <h1> per page (post title). Use <h2> for sections, <h3> for sub-sections. Never skip levels.
Image alt text Content
Every <img> must have descriptive alt text. Google Image Search uses this. Also critical for accessibility.
<img src="k8s-arch.png" alt="Kubernetes cluster architecture diagram showing pods, nodes, and services">
Internal linking Content
Link to your other related posts within content. Helps Google discover pages and distributes page authority. Aim for 3-5 internal links per post.
Clean URL structure Content
URLs should be short, descriptive, and contain keywords. Avoid dates in URL if possible. Use hyphens to separate words.
✅ /deploy-kubernetes-helm-guide ❌ /2026/01/post-123.html
2. Robots, Crawling & Indexing Critical
robots.txt Dashboard
Controls which pages search engines can crawl. For Blogger: Settings → Crawlers and indexing → Custom robots.txt
User-agent: * Allow: / Disallow: /search Disallow: /search? Disallow: /search/label/*? Disallow: /*?m=1 Disallow: /*?m=0 Sitemap: https://yoursite.com/sitemap.xml
Robots meta tags HTML
Page-level control. Index posts/pages, noindex search/archive/label pages to prevent thin content indexing.
<!-- Posts & Pages --> <meta name="robots" content="index, follow, max-snippet:-1, max-image-preview:large"> <!-- Archive/Search/Label pages --> <meta name="robots" content="noindex, follow">
Custom robots header tags Dashboard
Server-level noindex signals. Blogger: Settings → Crawlers → Custom robots header tags. Set Homepage & Posts to "index, follow". Archives & Search to "noindex, follow".
XML Sitemap submitted Dashboard
Submit your sitemap to Google Search Console. Blogger auto-generates one at /sitemap.xml
https://yoursite.com/sitemap.xml → Submit at: Google Search Console → Sitemaps
Google Search Console verified Dashboard
Verify site ownership at search.google.com/search-console. Monitor indexing, coverage errors, and search performance.
3. Structured Data (JSON-LD) Critical
WebSite schema (homepage) HTML
Enables sitelinks search box in Google. Add SearchAction for site search.
{ "@context": "https://schema.org", "@type": "WebSite", "name": "codecloudworld", "url": "https://yoursite.com/", "potentialAction": { "@type": "SearchAction", "target": "https://yoursite.com/search?q={search_term_string}", "query-input": "required name=search_term_string" } }
BlogPosting / Article schema (posts) HTML
Enables rich results: author name, date, image in search. Include headline, datePublished, author, publisher, mainEntityOfPage.
{ "@context": "https://schema.org", "@type": "BlogPosting", "headline": "Post Title", "datePublished": "2026-01-15", "author": { "@type": "Person", "name": "Author" }, "publisher": { "@type": "Organization", "name": "Site Name", "logo": { "@type": "ImageObject", "url": "https://..." } }, "mainEntityOfPage": { "@type": "WebPage", "@id": "https://..." } }
BreadcrumbList schema HTML
Shows breadcrumb trail in Google search results (Home › Category › Post). Improves click-through rate.
{ "@context": "https://schema.org", "@type": "BreadcrumbList", "itemListElement": [ { "@type": "ListItem", "position": 1, "name": "Home", "item": "https://..." }, { "@type": "ListItem", "position": 2, "name": "Post Title", "item": "https://..." } ] }
Test with Rich Results Test Dashboard
Validate your structured data at search.google.com/test/rich-results. Fix all errors and warnings.
4. Social Sharing (OG & Twitter Cards) Important
og:type HTML
article on posts, website on homepage. Controls how Facebook/LinkedIn display your link.
og:title, og:url, og:description, og:image, og:site_name HTML
All 5 tags required. og:image should be at least 1200x630px for best display. Test with Facebook Sharing Debugger.
Twitter Card tags HTML
summary_large_image for posts with images. Include twitter:title, twitter:description, twitter:image. Test with Twitter Card Validator.
Featured images on every post Content
Every post should have a featured image. This appears in social shares, Google Discover, and rich results. Minimum 1200x630px.
5. Performance & Core Web Vitals Critical
loading="lazy" on images HTML
Defers offscreen images. Don't lazy-load above-the-fold images (first image visible on load).
Font display=swap HTML
Prevents Flash of Invisible Text (FOIT). Text shows immediately with fallback font while custom font loads.
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap" rel="stylesheet">
Preconnect hints HTML
Early connection to CDNs/font servers saves 100-300ms per resource.
<link rel="preconnect" href="https://fonts.googleapis.com"> <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
Combine font requests HTML
Load multiple Google Fonts in a single request to reduce HTTP connections.
<!-- BAD: 2 requests --> <link href="...?family=Inter" rel="stylesheet"> <link href="...?family=Fira+Code" rel="stylesheet"> <!-- GOOD: 1 request --> <link href="...?family=Inter:wght@400;700&family=Fira+Code&display=swap" rel="stylesheet">
Lazy-load non-critical JS HTML
Load syntax highlighters, analytics, etc. only where needed. Use conditional loading or async/defer.
Remove unused CSS HTML
Dead CSS increases page weight and render time. Audit with Chrome DevTools → Coverage tab.
Test with PageSpeed Insights Dashboard
Run at pagespeed.web.dev. Aim for 90+ on mobile. Fix LCP, FID, CLS issues flagged.
6. Accessibility & Semantic HTML Important
Semantic HTML elements HTML
Use <header>, <main>, <nav>, <article>, <aside>, <footer> instead of generic divs.
aria-label on icon-only links HTML
Links with only an icon (search, menu, social) must have aria-label for screen readers.
<a href="/search" aria-label="Search this site">🔍</a>
aria-hidden on decorative elements HTML
Decorative SVGs/icons should have aria-hidden="true" so screen readers skip them.
rel="noopener noreferrer" on external links HTML
Security + performance. Prevents target page from accessing window.opener. Add target="_blank" for external links.
aria-label on <nav> elements HTML
If multiple navs exist, each needs a unique aria-label (e.g., "Main navigation", "Footer navigation").
7. Technical SEO Important
HTTPS enabled Dashboard
Google uses HTTPS as a ranking signal. Blogger enables it by default. Verify in Settings → HTTPS.
Mobile-friendly / responsive HTML
Google uses mobile-first indexing. Test with Google's Mobile-Friendly Test tool. Ensure viewport meta tag is set.
<meta name="viewport" content="width=device-width, initial-scale=1">
Favicon HTML
Shows in browser tabs, bookmarks, and Google search results. SVG preferred for crisp rendering at all sizes.
theme-color meta HTML
Colors the browser address bar on mobile. Matches your brand.
<meta name="theme-color" content="#0f172a">
Custom 404 error page HTML
Helps users find content when they hit a broken link. Include a link back to homepage and search.
No broken links Content
Check all internal/external links. Broken links hurt crawl budget and user experience. Use a link checker tool.
8. Content SEO Best Practices Ongoing
Write search descriptions for every post Content
In Blogger: Post settings → Search description. 150-160 chars, include primary keyword, call to action.
Target keywords in title, H1, first paragraph Content
Put your primary keyword in the title, H1, and first 100 words. Use variations naturally throughout the post.
Comprehensive content (1500+ words) Content
Longer, in-depth posts tend to rank better. Cover the topic thoroughly. Include examples, code snippets, images.
Use labels/categories consistently Content
Organize posts with consistent labels. Helps Google understand site structure and creates useful category pages.
Publish regularly Content
Consistent publishing signals an active site. Aim for at least 1-2 quality posts per week.

How Your Website Appears in Google Search

Google search results show different elements based on what structured data and meta tags you provide:

Standard Result:

codecloudworld.com › kubernetes-deploy-guide How to Deploy on Kubernetes with Helm | codecloudworld Step-by-step guide to deploying apps on Kubernetes with Helm charts, rolling updates, and monitoring...

With Rich Results (Article schema):

codecloudworld.com › kubernetes-deploy-guide How to Deploy on Kubernetes with Helm | codecloudworld Amit Kumar · Jan 15, 2026 — Step-by-step guide to deploying apps on Kubernetes with Helm charts...

With Breadcrumbs:

codecloudworld.com › Home › Kubernetes How to Deploy on Kubernetes with Helm | codecloudworld Step-by-step guide to deploying apps on Kubernetes...

With Sitelinks Search Box (WebSite schema):

codecloudworld — DevOps & MLOps Tutorials https://codecloudworld.com Join 250,000+ DevOps community. Weekly tutorials... ┌─────────────────────────────────────┐ │ 🔍 Search codecloudworld.com │ └─────────────────────────────────────┘ Kubernetes · Docker · CI/CD · About Us

Key things that control your Google appearance:

  • <title> → Blue clickable headline
  • meta description → Gray snippet text below title
  • Canonical URL → Green URL line shown
  • BreadcrumbList JSON-LD → Breadcrumb trail replaces URL
  • BlogPosting JSON-LD → Author name + date shown
  • WebSite JSON-LD + SearchAction → Sitelinks search box (homepage only)
  • Good site structure + internal links → Sitelinks (sub-pages shown below homepage result)
